# Galaxy of Nuclides adapter

Atlas integration boundary for `Frencil/galaxy_of_nuclides`.

Current status: **reference / selective adaptation candidate**.

No upstream source code is stored in this directory.

The main architectural interest is the interactive transformation between
elements, isotopes, the periodic table, and the chart of nuclides.

Atlas scientific data should remain separately sourced and provenance-aware.

See `references/upstream.json` and `docs/upstream-architecture.md`.
