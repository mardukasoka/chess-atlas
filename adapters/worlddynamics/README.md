# WorldDynamics.jl adapter

Atlas integration boundary for `worlddynamics/WorldDynamics.jl`.

Current status: **candidate executable dependency**.

No upstream source code is stored in this directory.

WorldDynamics.jl belongs primarily to the quantitative Julia layer:

Reality
→ Observation
→ Knowledge Graph
→ Julia / quantitative modelling
→ AI Council
→ Inform7
→ Interface

The adapter will eventually define how Atlas observations and parameters are
passed into world-system models and how model outputs return to the Atlas
without being confused with observations.

See `references/upstream.json` and `docs/upstream-architecture.md`.
