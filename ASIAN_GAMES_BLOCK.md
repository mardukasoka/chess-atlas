# Asian games block: Liubo → Go and beyond

This block begins the eastward game-history sequence while keeping chronology separate from descent.

## Liubo

Secure archaeological and visual evidence is strongest from the late Warring States period and especially the Han dynasty. Han-period museum objects preserve a marked board, twelve pieces (six per player), and chance equipment including dice. Earlier literary traditions may place Liubo further back, but sparse visual evidence means the Atlas must not promote those claims to the same certainty level.

Liubo is therefore represented as:

`attested equipment + archaeological context → incomplete rules evidence → no default playable ancient ruleset`

Any future playable Liubo implementation must name its reconstruction and author/source.

## Go / Weiqi

Go remains a separate, long-lived East Asian strategy-game lineage and already has a lightweight core module in Chess Atlas. Liubo and Go may occupy overlapping historical periods, but this block does **not** assert that Liubo evolved into Go.

## Next Asian sequence

After this evidence block, the intended research order is:

`Go / Weiqi → Chaturanga interactions and transmission questions → Xiangqi → Shogi → Janggi → Makruk / Ouk and related regional chess traditions`

That ordering is navigational, not a claim of a single genetic tree. Each game should carry its own earliest evidence, named rule profile where necessary, provenance, and uncertainty.
