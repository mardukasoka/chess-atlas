# Archaic Web v0.1

This directory is an isolated prototype for the story/archive layer reached later from the Future Infinite Board.

The public corpus is intentionally incomplete. It does not explain the Lattice, identify a canonical future, or claim that reconstructed memories are historical records.

## Formats

- `gemini/` contains Gemtext source pages.
- `gopher/` contains Gopher menus and plain-text representations.
- `web/` is the ordinary-browser mirror.
- `SOURCES.gmi` records story/source provenance.
- `OPEN_SOURCE.gmi` records software actually incorporated or adapted. Reference-only projects must be labelled as such.

A reconstructed fragment may be textually intact while its chronology, provenance, and reality-status remain unresolved.
