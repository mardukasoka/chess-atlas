# Ludus Latrunculorum implementation sources

Chess Atlas treats the ancient game and modern reconstructions as separate provenance layers.

Primary implemented profile: **Ulrich Schädler (1994)**.

Useful modern references for the reconstruction family include Ludii's Latrunculorum variant documentation and archaeoludological summaries comparing Schädler with other reconstructions. The Atlas implementation intentionally does not merge later or alternative features such as a *dux* into the Schädler 1994 profile.
